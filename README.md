# ✦ ZAYA Atelier

### **Your style. Your way.**

ZAYA Atelier is a premium digital commerce platform designed for the modern Algerian fashion boutique.

It combines an **editorial fashion storefront** with the operational tools a boutique needs to manage products, inventory, orders, customers, delivery, promotions, and customer communication.

Built with an **Algeria-first approach**, ZAYA supports French, Arabic with RTL, and English, Algerian Dinar pricing, Cash on Delivery, all 58 Wilayas, home delivery, and stop-desk pickup.

---

## ✨ Overview

Traditional Algerian clothing boutiques often manage their business across Instagram, Facebook, WhatsApp, spreadsheets, notebooks, and phone calls.

ZAYA Atelier brings that experience into one centralized platform.

### Customer

**Discover → Choose → Order → Track**

### Boutique

**Products → Inventory → Orders → Customers → Delivery → Analytics**

The result is more than a simple online store:

> **A premium storefront + a lightweight boutique management system.**

## 🎨 Variant-Level Inventory

ZAYA tracks inventory at the **size × color variant level**.

Example:

```text
Oversized Hoodie

Black / S → 3
Black / M → 7
Black / L → 4

White / S → 2
White / M → 5
White / L → 1
```

This prevents customers from ordering unavailable combinations.

The platform also displays low-stock indicators when inventory becomes limited.

# 🚀 Getting Started

Clone the repository:

```bash
git clone <repository-url>
cd <project-name>
```

Install dependencies:

```bash
npm install
```

Start the development environment:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

> Use the exact scripts and environment variables defined in the project's `package.json` and configuration files.

---

# 🔑 Environment Variables

Never commit real credentials to the repository.

If external services require credentials, configure them through environment variables.

Example:

```env
GEMINI_API_KEY=
DATABASE_URL=
AUTH_SECRET=
```

Only include variables that are actually required by the deployed implementation.
